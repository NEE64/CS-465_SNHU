# CS-465_SNHU
This is my private repository for the course CS-465 at SNHU.

- Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).
The code for the front-end can be found throughout the full-stack project. I opted to use .hbs alongside Express HTML in order to enhance the app's speed. The app is oriented towards clients and thus cannot connect with the backend to modify website information. Java is used for both the front and back ends, which allows for a dynamic nature. This is utilized to extract data from the MongoDB and significantly contributes to making the web page more user-friendly and aesthetically pleasing.

- Why did the backend use a NoSQL MongoDB database?
The NoSQL MongoDB database is known for being highly scalable and very easy to make changes to functionality. These features made it an ideal choice for the backend of the web application.

- How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?
JSON differs from Javascript in that JSON can format object data and is often easy to read with the Java language. Also, JavaScript can take data and convert it to an object in Java.
